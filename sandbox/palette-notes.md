# 世界书 FUI - 布色美化沙箱 (Palette Sandbox) 记录册

## 1. 目标
作为 Issue 2 阶段的工作区，这里完全独立于 `src/世界书美化/` 的正式代码。
专门用来测试主题颜色搭配、调试面板属性。

## 2. 包含的主题
我们初步预设了 3 套主题，可以通过右侧 Tweaks 面板顶部的 THEME_SELECT 自由切换：

- **Terminal Amber**: 终端琥珀。接近当前生产版本的深邃黑底+鲜明琥珀橙组合，对比度更高，更干练。
- **Old BBS FUI**: 老式论坛。采用青色/深青绿的冷色调，不刺眼，有一种复古控制台的感觉。
- **Codex Archive**: 档案库。非常冷静的纯黑/深灰背景，搭配 Claude UI 风格的橙色高亮，极其适合文字工作。
